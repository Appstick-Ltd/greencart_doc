# 🎨 Colors & Theme

Hana Go uses a centralized color system. Every color in the app is defined in one file — change it there and the entire app updates instantly.

---

## 📁 File

```
lib/constants/ui.dart
lib/theme/app.dart
```

---

## 🎨 Complete Color Palette

### Brand Colors

| Token | Hex | Usage |
|-------|-----|-------|
| `AppColors.primary` | `#004B30` | Buttons, active states, icons, headers |
| `AppColors.primaryLight` | `#006B47` | Hover/pressed states |
| `AppColors.mintGreen` | `#D2F6D2` | Chips, badges, tag backgrounds |
| `AppColors.lightMint` | `#EDFDF0` | Screen backgrounds, card fills |

### Accent Colors

| Token | Hex | Usage |
|-------|-----|-------|
| `AppColors.yellowAccent` | `#EAB308` | Ratings, pending status, limited offer badges |
| `AppColors.orangePrice` | `#D96126` | Discounted prices, flash sale labels |
| `AppColors.success` | `#22C55E` | Delivered status, success alerts, active tags |
| `AppColors.error` | `#EF4444` | Error states, cancelled badges, validation errors |

| Token | Hex | Usage |

## 📝 ui.dart

```dart
// lib/constants/ui.dart

import 'package:flutter/material.dart';

abstract class AppColors {
  AppColors._();

  // ── Brand ──────────────────────────────────────────
  static const Color primary      = Color(0xFF004B30);
  static const Color primaryLight = Color(0xFF006B47);
  static const Color mintGreen    = Color(0xFFD2F6D2);
  static const Color lightMint    = Color(0xFFEDFDF0);

  // ── Accent ─────────────────────────────────────────
  static const Color yellowAccent = Color(0xFFEAB308);

  static const Color error        = Color(0xFFEF4444);
  static const Color info         = Color(0xFF3B82F6);

  // ── Neutrals ───────────────────────────────────────
```

## 🔄 How to Change the Primary Brand Color

To rebrand Hana Go with your own colors, only edit `ui.dart`:

```dart
// Example: Changing to a blue brand
static const Color primary      = Color(0xFF1E40AF);  // Deep blue
static const Color primaryLight = Color(0xFF2563EB);  // Lighter blue
static const Color mintGreen    = Color(0xFFDBEAFE);  // Light blue tint
static const Color lightMint    = Color(0xFFEFF6FF);  // Very light blue
```

Hot reload the app and every button, icon, header, and active state updates automatically.

## 🌙 Material Theme Configuration

The full Material 3 theme is configured in `lib/theme/app.dart`:

```dart
// lib/theme/app.dart

ThemeData get lightTheme => ThemeData(
  useMaterial3: true,
  colorScheme: ColorScheme.fromSeed(
    seedColor: AppColors.primary,
    primary: AppColors.primary,
    onPrimary: AppColors.white,
    secondary: AppColors.mintGreen,
    surface: AppColors.white,
    error: AppColors.error,
    brightness: Brightness.light,
  ),
  fontFamily: 'Manrope',
  scaffoldBackgroundColor: AppColors.white,
  appBarTheme: const AppBarTheme(
    backgroundColor: AppColors.white,
    foregroundColor: AppColors.black,
    elevation: 0,
    centerTitle: true,
  ),
  elevatedButtonTheme: ElevatedButtonThemeData(
    style: ElevatedButton.styleFrom(
      backgroundColor: AppColors.primary,
      foregroundColor: AppColors.white,
      shape: RoundedRectangleBorder(
        borderRadius: BorderRadius.circular(12),
      ),
      minimumSize: const Size.fromHeight(52),
    ),
  ),
);
```

## 🎨 Semantic Color Usage Guidelines

| Situation | Color to Use |
|-----------|-------------|
| Primary action button | `AppColors.primary` |
| Destructive action | `AppColors.error` |
| Success confirmation | `AppColors.success` |
| Warning / attention | `AppColors.yellowAccent` |
| Discounted price | `AppColors.orangePrice` |
| Inactive/disabled state | `AppColors.grey400` |
| Card background | `AppColors.grey100` or `AppColors.white` |
| Page background | `AppColors.white` |
| Input field background | `AppColors.grey100` |
| Divider lines | `AppColors.grey200` |

---

:::tip One File, App-Wide Impact
Since every widget uses `AppColors.primary` (not hard-coded hex values), changing your brand color is a **single-line edit** in `ui.dart`. The entire app — 26 screens — reflects the change immediately on hot reload.
:::
