# Localization

Hana Go ships with **9 languages** out of the box using Flutter's built-in localization with GetX for runtime language switching.

---

## Files

```
assets/translations/          ← One JSON file per language
lib/utils/extensions/string.dart   ← Language definitions
lib/pages/settings/language/
├── language_view.dart
└── language_controller.dart
```

## Using Translations in Code

GetX provides the `.tr` extension on strings to load the correct translation.

```dart
// In any widget:
Text('add_to_cart'.tr)           // → "Add to Cart" (en) or "Ajouter au panier" (fr)
Text('welcome_title'.tr)         // → "Welcome Back!" (en) or "Bienvenue !" (fr)

// With arguments (parameterized):
Text('items_count'.trArgs(['5'])) // → "5 items in cart"
// JSON: "items_count": "@count items in cart"
```

## Adding a New Language

### Step 1 — Create the Translation File

Create `assets/translations/ja_JP.json` (example: Japanese).

```json
{
  "app_name": "ハナゴー",
  "welcome_title": "おかえりなさい！",
  "login": "サインイン",
  "register": "アカウント作成",
  "add_to_cart": "カートに追加",
  "home": "ホーム",
  "cart": "カート",
  "settings": "設定"
}
```

:::warning
Every key present in `en_US.json` must also be in your new language file. Missing keys fall back to the key name itself (not ideal for production).
:::

### Step 2 — Declare Asset in pubspec.yaml

Add the new language file to the assets list.

```yaml
flutter:
  assets:
    - assets/translations/
    - assets/translations/ja_JP.json   # Add this line
```

### Step 3 — Add Language Definition

Add the new language to the supported languages list.

```dart
// lib/utils/extensions/string.dart

class AppLanguage {
  final String name;
  final String flag;
  final String code;
  final Locale locale;
  
  const AppLanguage({
    required this.name,
    required this.flag,
    required this.code,
    required this.locale,
  });
}

const kSupportedLanguages = [
  AppLanguage(name: 'English (US)', flag: '', code: 'en_US', locale: Locale('en', 'US')),
  AppLanguage(name: 'German',       flag: '', code: 'de_DE', locale: Locale('de', 'DE')),
  AppLanguage(name: 'Spanish',      flag: '', code: 'es_ES', locale: Locale('es', 'ES')),
  AppLanguage(name: 'French',       flag: '', code: 'fr_FR', locale: Locale('fr', 'FR')),
  AppLanguage(name: 'Italian',      flag: '', code: 'it_IT', locale: Locale('it', 'IT')),
  AppLanguage(name: 'Indonesian',   flag: '', code: 'id_ID', locale: Locale('id', 'ID')),
  // Add new language:
  AppLanguage(name: 'Japanese',     flag: '', code: 'ja_JP', locale: Locale('ja', 'JP')),
];
```

### Step 4 — Add Locale to GetMaterialApp

Register the new locale in the main app configuration.

```dart
// main.dart
GetMaterialApp(
  translations: AppTranslations(),
  locale: _savedLocale,
  fallbackLocale: const Locale('en', 'US'),
  supportedLocales: kSupportedLanguages.map((l) => l.locale).toList(),
  localizationsDelegates: const [
    GlobalMaterialLocalizations.delegate,
    GlobalWidgetsLocalizations.delegate,
    GlobalCupertinoLocalizations.delegate,
  ],
  ...
)
```

The new language will automatically appear in the Language settings screen.

## Switching Language at Runtime

This code handles language selection and saves the user's choice.

```dart
// language_controller.dart
void selectLanguage(AppLanguage lang) {
  Get.updateLocale(lang.locale);
  GetStorage().write('locale', lang.code);  // Persist choice
}
```

On next app launch, the saved locale is restored.

```dart
// main.dart
final savedCode = GetStorage().read<String>('locale') ?? 'en_US';
final savedLocale = kSupportedLanguages
    .firstWhere((l) => l.code == savedCode)
    .locale;
```

## Right-to-Left (RTL) Support

To add Arabic or Hebrew (RTL languages), add this to `GetMaterialApp`.

```dart
GetMaterialApp(
  locale: arabicLocale,
  // Flutter automatically flips layout direction for RTL locales
  // No additional code needed for most widgets
)
```

RTL-aware widgets like `Row`, `Padding`, and `Align` automatically flip. For custom directional layouts, use `Directionality.of(context)`.
