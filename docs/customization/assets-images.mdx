# 🖼️ Assets & Images

All static assets are organized under the `assets/` directory, declared in `pubspec.yaml`, and accessed via typed paths throughout the app.

---

## 📁 Asset Directory Structure

```
assets/
├── data/
│   └── products.json              ← Mock product catalogue
├── font/
│   └── Manrope/static/            ← 7 font weight TTF files
├── icons/
│   ├── logo.png                   ← App logo (used for launcher icon)
│   ├── navi_icon/                 ← Bottom nav bar SVG icons (5 icons)
│   ├── setting/                   ← Settings menu SVG icons
│   │   └── setting/               ← Nested settings sub-icons
│   ├── home_screen image/         ← Home screen decorative assets
│   ├── ai recom/                  ← AI recommendation section icons
│   ├── daily purchase/            ← Daily purchase item icons
│   └── catagory/                  ← Category icons (per category folder)
│       ├── vegetables/
│       ├── fruits/
│       ├── dairy/
│       ├── pantry/
│       ├── beverage/
│       ├── frozen/
│       ├── household/
│       ├── snacks/
│       └── snack&package/
├── images/                        ← General product & UI images
└── translations/                  ← Localization JSON files
```

## 🔄 Replacing the App Logo

1. Replace `assets/icons/logo.png` with your logo (recommended: **1024×1024px PNG** with transparent background)
2. Run the launcher icon generator:

```bash
dart run flutter_launcher_icons
```

This updates the launcher icon on **Android, iOS, Web, Windows, and macOS** automatically based on `pubspec.yaml`:

```yaml
# pubspec.yaml
flutter_launcher_icons:
  android: "launcher_icon"
  ios: true
  image_path: "assets/icons/logo.png"
  adaptive_icon_background: "#0D3D31"   # ← Change to your brand color
  adaptive_icon_foreground: "assets/icons/logo.png"
```

## 🎨 SVG Icons

Hana Go uses **SVG icons** exclusively (via `flutter_svg`) for crisp rendering at any density.

### Loading an SVG

```dart
import 'package:flutter_svg/flutter_svg.dart';

// From asset path:
SvgPicture.asset(
  'assets/icons/navi_icon/home.svg',
  width: 24.w,
  height: 24.h,
  colorFilter: ColorFilter.mode(AppColors.primary, BlendMode.srcIn),
)
```

### Replacing Category Icons

Each category folder contains a single `.svg` file. To replace:
1. Prepare your SVG (ideally 48×48dp viewBox, single-path or simple shapes)
2. Drop it into the appropriate category folder, e.g. `assets/icons/catagory/vegetables/veg.svg`
3. Reference it in the category data:

```dart
// home_quick_categories.dart or category_controller.dart
const _kQuickCategories = [
  _QuickCategoryItem(
    label: 'Vegetables',
    iconPath: 'assets/icons/catagory/vegetables/veg.svg',
    route: Routes.productListView,
    argument: 'vegetables',
  ),
];
```

## 🖼️ Product Images

### Mock Mode (default)

Product images are loaded from the JSON data file. During development, they use either:
- Local asset paths: `assets/images/product_name.png`
- Remote URLs (served by `cached_network_image`)

### Production Mode

Replace local assets with real CDN URLs in your product API response:

```json
{
  "id": "prod_001",
  "name": "Fresh Broccoli",
  "imageUrl": "https://cdn.yourstore.com/products/broccoli.webp",
  "imageUrls": [
    "https://cdn.yourstore.com/products/broccoli_1.webp",
    "https://cdn.yourstore.com/products/broccoli_2.webp"
  ]
}
```

`CachedNetworkImage` handles downloading, caching, and shimmer placeholders automatically:

```dart
// lib/components/hana_image.dart
CachedNetworkImage(
  imageUrl: product.imageUrl,
  placeholder: (ctx, url) => const ShimmerBox(),
  errorWidget: (ctx, url, err) => SvgPicture.asset('assets/icons/image_placeholder.svg'),
  fit: BoxFit.cover,
)
```

## 📦 Declaring New Assets

After adding any new file to the `assets/` directory, declare it in `pubspec.yaml`:

```yaml
flutter:
  assets:
    - assets/                       # Catches root-level files
    - assets/images/                # All files in images/
    - assets/icons/my_new_folder/   # New folder you created
```

Then run:
```bash
flutter pub get
```

## 🗜️ Image Optimization Tips

| Format | Use Case | Recommended Tool |
|--------|----------|-----------------|
| **PNG** | Logo, icons with transparency | TinyPNG, pngquant |
| **WebP** | Product photos (best compression) | cwebp, Squoosh |
| **SVG** | UI icons, illustrations | SVGO |
| **AVIF** | Future-proof photos | Squoosh |

Keep product images under **100KB** for fast loading on slow connections.

---

:::tip Asset Access Pattern
Never hardcode asset paths as inline strings in widget files. Define them as constants:
```dart
// lib/constants/app_assets.dart
abstract class AppAssets {
  static const String logo = 'assets/icons/logo.png';
  static const String homeNav = 'assets/icons/navi_icon/home.svg';
  // ...
}

// Usage:
SvgPicture.asset(AppAssets.homeNav)
```
This makes asset renaming safe and IDE-navigable.
:::
