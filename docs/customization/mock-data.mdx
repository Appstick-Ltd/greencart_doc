# 🔌 Mock Data → Real API

Hana Go ships with a complete mock data layer so you can explore every screen without a backend. This guide walks you through swapping mock data for real API calls — without changing any UI code.

---

## 🏗️ Data Layer Architecture

```
UI (Views)
    ↕ observes reactive state (Obx / GetX)
Controllers
    ↕ calls
Data Loaders / Services
    ↕ returns List<Model>
Mock Seeds  ←→  Real API (your backend)
```

The key insight: **controllers only care about `List<ProductModel>`, not where the data came from.** Swapping the data source is isolated to the loader/service layer.

## 🛒 Step 1 — Replace Products API

### Before (Mock)

```dart
// lib/data/loaders/product_loader.dart

class ProductLoader {
  Future<List<ProductModel>> loadAll() async {
    final json = await rootBundle.loadString('assets/data/products.json');
    final List data = jsonDecode(json);
    return data.map((e) => ProductModel.fromJson(e)).toList();
  }

  Future<List<ProductModel>> loadByCategory(String category) async {
    final all = await loadAll();
    return all.where((p) => p.category == category).toList();
  }
}
```

### After (Real API)

```dart
// lib/data/loaders/product_loader.dart

class ProductLoader {
  final Dio _dio;
  ProductLoader(this._dio);

  Future<List<ProductModel>> loadAll({int page = 1, int limit = 20}) async {
    final response = await _dio.get(
      '/products',
      queryParameters: {'page': page, 'limit': limit},
    );
    return (response.data['data'] as List)
        .map((e) => ProductModel.fromJson(e))
        .toList();
  }

  Future<List<ProductModel>> loadByCategory(String category, {int page = 1}) async {
    final response = await _dio.get(
      '/products',
      queryParameters: {'category': category, 'page': page, 'limit': 20},
    );
    return (response.data['data'] as List)
        .map((e) => ProductModel.fromJson(e))
        .toList();
  }

  Future<ProductModel> loadById(String id) async {
    final response = await _dio.get('/products/$id');
    return ProductModel.fromJson(response.data);
  }
}
```

**The controllers and views are unchanged.**

## 🔐 Step 2 — Replace Authentication

```dart
// lib/services/auth_service.dart

class AuthService extends GetxService {
  final Dio _dio;
  AuthService(this._dio);

  Future<AuthResponse> login({required String email, required String password}) async {
    final response = await _dio.post('/auth/login', data: {
      'email': email,
      'password': password,
    });
    return AuthResponse.fromJson(response.data);
  }

  Future<AuthResponse> register({
    required String name,
    required String email,
    required String password,
    required String phone,
  }) async {
    final response = await _dio.post('/auth/register', data: {
      'name': name, 'email': email,
      'password': password, 'phone': phone,
    });
    return AuthResponse.fromJson(response.data);
  }

  Future<void> forgotPassword(String email) async {
    await _dio.post('/auth/forgot-password', data: {'email': email});
  }

  Future<void> verifyOtp({required String email, required String otp}) async {
    await _dio.post('/auth/verify-otp', data: {'email': email, 'otp': otp});
  }
}
```

## 📦 Step 3 — Replace Orders API

```dart
// Replace orders_seed.dart usage in my_orders_controller.dart:

Future<void> loadOrders() async {
  isLoading.value = true;
  final response = await _dio.get('/orders', queryParameters: {
    'userId': _authService.currentUserId,
    'page': currentPage.value,
    'limit': 10,
  });
  
  if (currentPage.value == 1) {
    orders.value = (response.data['data'] as List)
        .map((e) => OrderModel.fromJson(e)).toList();
  } else {
    orders.addAll((response.data['data'] as List)
        .map((e) => OrderModel.fromJson(e)));
  }
  
  hasMore.value = response.data['hasMore'] ?? false;
  isLoading.value = false;
}
```

## 🌐 Configuring Dio (HTTP Client)

Set up a single `Dio` instance with interceptors for auth headers, logging, and error handling:

```dart
// lib/services/api_service.dart

class ApiService {
  late final Dio dio;

  ApiService() {
    dio = Dio(BaseOptions(
      baseUrl: 'https://api.yourstore.com/v1',
      connectTimeout: const Duration(seconds: 10),
      receiveTimeout: const Duration(seconds: 30),
      headers: {'Content-Type': 'application/json'},
    ));

    // Auth token interceptor
    dio.interceptors.add(InterceptorsWrapper(
      onRequest: (options, handler) {
        final token = LocalStorageService.getToken();
        if (token != null) options.headers['Authorization'] = 'Bearer $token';
        handler.next(options);
      },
      onError: (error, handler) {
        if (error.response?.statusCode == 401) {
          // Token expired — logout
          Get.find<AuthService>().logout();
        }
        handler.next(error);
      },
    ));

    // Logging in debug mode
    if (kDebugMode) {
      dio.interceptors.add(LogInterceptor(responseBody: true));
    }
  }
}
```
