## 📂 Adding Your Screenshots

### Step 1 — Take Screenshots
Use your device or emulator. Recommended devices:
- **Android**: Pixel 8 (412×915px) at default scale
- **iOS**: iPhone 15 Pro (393×852px) at default scale

### Step 2 — Name the Files
Follow the filename convention in the tables above (e.g. `splash.png`, `home.png`).

### Step 3 — Place in the Screenshots Folder

```
hana_go_docs/
└── static/
    └── img/
        └── screenshots/
            ├── splash.png          ← Add here
            ├── home.png
            ├── login.png
            └── ...                 ← All files listed above
```

### Step 4 — Restore Image Markdown

Once files are in place, replace the filename tables above with image markdown:

```markdown
![Splash Screen](/img/screenshots/splash.png)
![Home Screen](/img/screenshots/home.png)
```

## 📐 Recommended Screenshot Specifications

| Property | Value |
|----------|-------|
| Format | PNG or WebP |
| Resolution | 390×844px or 412×915px |
| Orientation | Portrait only |
| Background | Clean — no OS chrome overlays |
| Max file size | 200KB per image |

- Show your best 5–8 screens in the preview images to maximize conversion
