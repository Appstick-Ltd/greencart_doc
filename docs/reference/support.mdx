# 🆘 Support

Thank you for purchasing **Hana Go**! We're here to help you succeed.

---

## 📬 How to Get Support

### Step 1 — Search the Documentation
Most questions are answered in this documentation. Use the **search bar** at the top of any page, or browse the sidebar categories.

### Step 2 — Check the FAQ
Visit the **[FAQ page](./faq)** for answers to the most common questions about setup, customization, and backend integration.

### Step 3 — Contact Support

If you can't find your answer, contact us via the **CodeCanyon item page** or directly:

| Channel | Details | Response Time |
|---------|---------|---------------|
| 📧 **CodeCanyon Comments** | Post on the item's comment section | 1–2 business days |
| 📧 **Email Support** | support@hanago-template.com | 1–2 business days |
| 💬 **Live Chat** | Available Mon–Fri 9AM–6PM UTC | Within a few hours |

---

## 📋 What to Include in Your Support Request

To help us resolve your issue as quickly as possible, please provide:

1. **Purchase code** — Found in your CodeCanyon account → Downloads → License Certificate
2. **Flutter version** — Output of `flutter --version`
3. **Platform** — Android / iOS / both
4. **Device/emulator** — Model and OS version
5. **Description** — What you expected vs. what happened
6. **Error message** — Copy the full error from the terminal or IDE
7. **Steps to reproduce** — Numbered list of steps to trigger the issue
8. **Screenshots** — If applicable

---

## ✅ What's Covered by Support

| Covered ✅ | Not Covered ❌ |
|------------|----------------|
| Bugs in the original template code | Customization services |
| Setup and installation issues | New feature development |
| Questions about how the template works | Third-party API issues (Firebase, Google Places, etc.) |
| Flutter version compatibility issues | Issues caused by your custom code changes |
| Documentation corrections | General Flutter/Dart learning support |

:::info Support Period
Envato standard support covers **6 months** from the date of purchase. After 6 months, you can renew support or reference the documentation and community for help.
:::

## 🐛 Reporting Bugs

Found a bug in the original template? Please report it with:

```
Bug Report Template:

**Flutter version:** 3.xx.x
**Platform:** Android / iOS
**Device:** Pixel 8 / iPhone 15 / emulator
**OS version:** Android 14 / iOS 17

**Expected behavior:**
[What should happen]

**Actual behavior:**
[What actually happens]

**Steps to reproduce:**
1. Open the app
2. Navigate to [screen]
3. Tap [button]
4. See error

**Error output:**
[Paste terminal or console error here]
```
