# 📋 Changelog

All notable changes to **Hana Go** are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] — June 2026 🎉 Initial Release

### ✨ Added

#### Screens (26+)
- **Splash Screen** — animated logo with brand color background
- **Onboarding** — 2-slide carousel with skip/next functionality
- **Welcome Screen** — CTA gateway to Login and Register
- **Login Screen** — email/password with country code picker and remember-me
- **Register Screen** — full registration form with validation
- **Forgot Password → OTP Verification → New Password** — complete password recovery flow
- **Home Screen** — hero banner, quick categories, limited offers, AI recommendations, daily purchases
- **Category View** — 8 grocery categories with sub-filter chips
- **Product List** — grid/list view with filter drawer and sort options
- **Product Details** — image gallery, variants, stock status, related products
- **All Products** — full catalogue with real-time search
- **Wishlist** — save products, move to cart, swipe to remove
- **Hana AI Chat** — text chat, voice input (speech_to_text), product cards, recipe cards, add-to-cart sheet
- **Cart View** — item management, quantity controls, price summary
- **Checkout** — address selection, delivery scheduling, coupon application, payment selection
- **Date & Time Picker** — 7-day calendar strip + time slot grid
- **Order Confirmed** — animated success screen with order summary
- **My Orders** — order history with status badges
- **Track Order** — step-by-step delivery timeline
- **Settings Hub** — profile card + 11 settings actions
- **Account / Personal Information** — editable profile with photo picker
- **Delivery Addresses** — list, add, edit, delete, set default
- **Payment Methods** — card wallet with add/remove
- **Notifications** — categorized list with mark-as-read, detail view
- **Change Password** — current + new + confirm with strength meter
- **Language Selection** — 9 languages with flag display
- **Privacy & Sharing** — policy content screen
- **FAQ** — expandable accordion list
- **Coupons** — coupon wallet with copy-to-clipboard
- **Contact Us Bottom Sheet** — call, email, live chat placeholders

#### Architecture
- **GetX** state management, routing, and dependency injection throughout
- **Feature-first** folder structure (`lib/pages/<feature>/`)
- **Service layer** — CartService, WishlistService, NotificationService, ProfileService, LocalStorageService
- **Bindings** for all 26+ routes ensuring clean dependency lifecycle
- Centralized **AppColors**, **AppTextStyles**, **AppTheme** tokens
- **Route constants** in `Routes` class (zero bare strings)
- **Mock data layer** — `lib/data/seeds/` + `assets/data/products.json`

#### Customization
- **9 languages** — en_US, en_GB, de_DE, es_ES, fr_FR, it_IT, id_ID + 2 alternates
- **Manrope font** — 7 weights (ExtraLight to ExtraBold)
- **flutter_screenutil** — fully responsive on all screen sizes
- **flutter_launcher_icons** — single-command icon generation for all platforms

#### Integrations
- **Firebase Core + FCM** — push notifications pre-configured
- **Google Places Flutter** — address autocomplete in edit address
- **speech_to_text** — voice input for Hana AI
- **image_picker** — profile photo picker (gallery + camera)
- **country_code_picker** — phone country code selector
- **cached_network_image + shimmer** — async image loading with skeletons
- **dio** — HTTP client ready for API integration
- **url_launcher** — call support and email actions in Contact Us
- **pinput** — OTP PIN input with animations
- **share_plus** — product sharing via native share sheet

#### Documentation
- Full **Docusaurus** documentation site included in package
- 20+ documentation pages covering all features, architecture, and customization
- Code examples for every integration point
- Mock → Real API migration guide
