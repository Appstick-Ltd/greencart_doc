# Managing Products

This guide explains how products are structured, categorized, and added to the Hana Go grocery catalog.

## Product Schema

Each product in Hana Go contains the following attributes:

```json
{
  "id": "prod_veg_cauliflower_01",
  "name": "Fresh Cauliflower",
  "category": "Vegetables",
  "unit": "1 pc",
  "originalPrice": 45.00,
  "discountedPrice": 35.00,
  "inStock": true,
  "image": "assets/images/products/cauliflower.png",
  "tags": ["Fresh", "Organic", "Vegetables"]
}
```

---

## Adding a New Product

To add a new product to the inventory:

### 1. Place the Image Asset
Save the product image under the static directory `static/img/products/`. Recommended resolution is `500x500` pixels with a transparent background.

### 2. Update the Inventory DB
Navigate to the product service and insert the new item entry.

### 3. Verify on the UI
Search for the item under the **Categories** grid (e.g., *Vegetables* or *Fruits*) to verify that the price, discount tag, and unit are displayed correctly.
