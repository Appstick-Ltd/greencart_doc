# Congratulations!

You have just learned the **basics of Hana Go** and made some changes to the **initial template**.

Hana Go has **much more to offer**!

Have **5 more minutes**? Take a look at **[versioning](../tutorial-extras/manage-docs-versions.mdx)** and **[i18n](../tutorial-extras/translate-your-site.mdx)**.

Anything **unclear** or **buggy** in this tutorial? [Please report it!](https://github.com/facebook/Hana Go/discussions/4610)

## What's next?

- Read the [official documentation](https://Hana Go.io/)
- Modify your site configuration with [`Hana Go.config.js`](https://Hana Go.io/docs/api/Hana Go-config)
- Add navbar and footer items with [`themeConfig`](https://Hana Go.io/docs/api/themes/configuration)
- Add a custom [Design and Layout](https://Hana Go.io/docs/styling-layout)
- Add a [search bar](https://Hana Go.io/docs/search)
- Find inspirations in the [Hana Go showcase](https://Hana Go.io/showcase)
- Get involved in the [Hana Go Community](https://Hana Go.io/community/support)
