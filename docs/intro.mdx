# Project Overview

Welcome to the **Hana Go** developer documentation! 

Hana Go is a premium, modern **Grocery E-Commerce Mobile UI Template** designed to speed up the development of shopping applications. It offers a complete, highly-polished set of pre-built Flutter screens, smooth micro-animations, and interactive layouts.

---

## 🚀 Pre-built UI Screens & Features

* **Beautiful Home Screen**: Features location badges, banner carousel sliders, category selector grids, and product recommendations.
* **Category Grids**: Pre-configured layout templates for Vegetables, Fruits, Dairy, Pantry, Snacks, Beverages, Frozen, and Household items.
* **Hana AI & Recipes UI**: Beautifully designed layouts for interactive AI assistants and step-by-step recipe checkout experiences.
* **Cart & Checkout Layouts**: Smooth bottom sheet cart presentation and modern billing details screen structures.

---

## 🛠️ Tech Stack & Architecture

Hana Go is built as a pure client-side frontend template:

| Component | Technology | Description |
| :--- | :--- | :--- |
| **Mobile Client** | Flutter & Dart | Cross-platform mobile template for iOS and Android, focusing on premium UI/UX aesthetics. |
| **State & Navigation** | GetX / Provider | Clean navigation routing and reactive UI state controllers for mocking user interactions. |
| **UI Aesthetics** | Custom HSL Colors | Curated dark forest green color palette, elegant typography, and modern cards/button states. |
