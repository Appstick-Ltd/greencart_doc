**Hana Go** is a premium, production-ready **Grocery E-Commerce Mobile App UI Template** built with Flutter. It delivers an entire app experience — from onboarding to checkout and order tracking — with a beautiful dark-green design system, an integrated AI shopping assistant, and clean GetX architecture that makes backend integration straightforward.

Whether you're a developer looking to ship a grocery app fast, or a business that wants a polished starting point, **Hana Go saves you hundreds of hours** of design and development time.

## 🚀 Key Highlights

### 🏠 Premium Home Screen
Interactive hero banner slider, quick category grid (8 categories), limited offers section, AI recommendation strip, and daily purchase suggestions — all wired with smooth animations.

### 🤖 Hana AI Assistant
A fully built AI chat UI with voice input via `speech_to_text`, waveform animations, conversational product cards, recipe suggestion cards, and an add-to-cart bottom sheet — ready to wire to any LLM backend.

### 🛍️ Complete Cart & Checkout
Multi-step checkout with saved address selection, delivery date/time picker, coupon code application, promo discounts, price summary breakdown, and a beautiful order confirmed screen.

### ⚙️ Full Settings Suite
Profile management, delivery addresses (add/edit), payment methods, notification preferences, language selector, privacy settings, FAQ, and coupon wallet — all pre-built.

### 🔐 Authentication Flows
Splash → Onboarding → Welcome → Login → Register → Forgot Password → OTP Verification → New Password. Complete flow with country code picker and PIN input.
