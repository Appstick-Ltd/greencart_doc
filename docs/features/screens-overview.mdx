## 🎬 Screen Inventory

### 🌟 Onboarding & Auth (8 screens)

| Screen | Route | Description |
|--------|-------|-------------|
| **Splash** | `/splash` | Animated logo with brand colors, 2-second auto-navigate |
| **Onboarding** | `/onboarding` | 2-slide carousel with skip/next, persisted first-visit |
| **Welcome** | `/welcome` | CTA to Login or Register |
| **Login** | `/login` | Email + password, country code picker, remember me |
| **Register** | `/register` | Full registration form with validation |
| **Forgot Password** | `/forgot-password` | Email entry for password reset flow |
| **OTP Verification** | `/otp-verification` | 6-digit PIN input using `pinput`, resend timer |
| **New Password** | `/new-password` | Set new password with strength indicator |

---

### 🏠 Home (1 screen, 5 section widgets)

| Component | Description |
|-----------|-------------|
| **Hero Banner** | Auto-sliding promotional banner with page indicator dots |
| **Quick Categories** | 8-category horizontal scroll (Vegetables, Fruits, Dairy, Pantry, Snacks, Beverages, Frozen, Household) |
| **Limited Offers** | Horizontally scrollable discount product cards with countdown |
| **AI Recommendations** | Personalized product cards from Hana AI strip |
| **Daily Purchase** | Frequently ordered items for quick re-order |

---

### 🛍️ Shopping (5 screens)

| Screen | Route | Description |
|--------|-------|-------------|
| **Category View** | `/category` | Browse by category with sub-filter chips |
| **Product List** | `/product-list` | Grid/list toggle, filter drawer, sort options |
| **Product Details** | `/product-details` | Images, description, variants, stock, add to cart |
| **All Products** | `/all-products` | Full catalogue grid with search |
| **Wishlist** | `/wishlist` | Saved items, move to cart action |

---

### 🤖 Hana AI (1 screen)

| Feature | Description |
|---------|-------------|
| **Text Chat** | Type queries, get product recommendations as chat bubbles |
| **Voice Input** | Tap microphone → speak → auto-transcribe via `speech_to_text` |
| **Product Cards** | Inline product cards in chat with add-to-cart action |
| **Recipe Cards** | Recipe suggestions with ingredient lists and cooking steps |
| **Add to Cart Sheet** | Bottom sheet to add recommended items to cart |

---

### 🛒 Cart & Checkout (5 screens)

| Screen | Route | Description |
