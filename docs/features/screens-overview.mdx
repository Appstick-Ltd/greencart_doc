# Screens Overview

## Screen Inventory

### Onboarding and Auth (8 screens)

| Screen | Route | Description |
|--------|-------|-------------|
| **Splash** | `/splash` | Animated logo with brand colors. Auto-navigates after 2 seconds. |
| **Onboarding** | `/onboarding` | 2-slide carousel with skip/next. Saved on first visit. |
| **Welcome** | `/welcome` | Call-to-action buttons for Login or Register. |
| **Login** | `/login` | Email and password fields. Country code picker. Remember me option. |
| **Register** | `/register` | Full registration form with validation. |
| **Forgot Password** | `/forgot-password` | Enter email to start password reset. |
| **OTP Verification** | `/otp-verification` | 6-digit PIN input with resend timer. |
| **New Password** | `/new-password` | Set new password with strength indicator. |

---

### Home (1 screen, 5 section widgets)

| Component | Description |
|-----------|-------------|
| **Hero Banner** | Auto-sliding promotional banner with page indicator dots. |
| **Quick Categories** | 8-category horizontal scroll (Vegetables, Fruits, Dairy, Pantry, Snacks, Beverages, Frozen, Household). |
| **Limited Offers** | Horizontally scrollable discount product cards with countdown. |
| **AI Recommendations** | Personalized product cards from the Hana AI engine. |
| **Daily Purchase** | Frequently ordered items for quick re-order. |

---

### Shopping (5 screens)

| Screen | Route | Description |
|--------|-------|-------------|
| **Category View** | `/category` | Browse by category with sub-filter chips. |
| **Product List** | `/product-list` | Grid/list toggle, filter drawer, sort options. |
| **Product Details** | `/product-details` | Images, description, variants, stock status, add to cart. |
| **All Products** | `/all-products` | Full catalogue grid with search. |
| **Wishlist** | `/wishlist` | Saved items with move-to-cart action. |

---

### Hana AI (1 screen)

| Feature | Description |
|---------|-------------|
| **Text Chat** | Type queries, get product recommendations as chat bubbles. |
| **Voice Input** | Tap microphone, speak, auto-transcribe. |
| **Product Cards** | Inline product cards in chat with add-to-cart button. |
| **Recipe Cards** | Recipe suggestions with ingredient lists and cooking steps. |
| **Add to Cart Sheet** | Bottom sheet to add recommended items to cart. |

---

### Cart and Checkout (5 screens)

| Screen | Route | Description |
|--------|-------|-------------|
| **Cart** | `/cart` | Item list, quantity controls, subtotal, proceed button. |
| **Checkout** | `/checkout` | Address selector, delivery slot, coupon, price breakdown, payment. |
| **Date and Time** | `/date-and-time` | Calendar and time slot picker for delivery scheduling. |
| **Order Confirmed** | `/order-confirmed` | Animated success screen with order summary. |
| **My Orders** | `/my-orders` | Order history with status badges. |
| **Track Order** | `/track-order` | Step-by-step order tracking view. |

---

### Settings (11 screens)

| Screen | Route | Description |
|--------|-------|-------------|
| **Settings Hub** | `/settings` (via bottom nav) | Profile card and quick action buttons. |
| **Account** | `/account` | Edit personal info, profile photo. |
| **Delivery Addresses** | `/delivery-address` | Saved address list with default selection. |
| **Edit Address** | `/edit-address` | Add or edit address with autocomplete. |
| **Payment Methods** | `/payment-method` | Credit/debit cards with card widget. |
| **Notifications** | `/notification` | Notification list with categories. |
| **Notification Detail** | `/notification-details` | Full notification content view. |
| **Change Password** | `/change-password` | Secure password update form. |
| **Language** | `/language` | 9-language selector with flag icons. |
| **Privacy and Sharing** | `/privacy-sharing` | Privacy policy content. |
| **FAQ** | `/faq` | Expandable accordion FAQ list. |
| **Coupons** | `/coupons` | Available coupon wallet. |
