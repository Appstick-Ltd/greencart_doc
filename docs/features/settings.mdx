## Settings Hub

**Route:** `/settings` (bottom nav — 5th tab)

The settings hub displays:
1. Profile Card (top) — avatar, name, email, "Edit Profile" button
2. Action Buttons List — tappable rows with icon, label, and arrow

### Settings Menu Items

| Icon | Label | Route |
|------|-------|-------|
| Person | My Account | `/account` |
| Pin | Delivery Address | `/delivery-address` |
| Card | Payment Method | `/payment-method` |
| Bell | Notifications | `/notification` |
| Lock | Change Password | `/change-password` |
| Globe | Language | `/language` |
| Shield | Privacy and Sharing | `/privacy-sharing` |
| Question | FAQ | `/faq` |
| Ticket | Coupons | `/coupons` |
| Phone | Contact Us | Bottom Sheet |
| Door | Logout | Clears storage, goes to `/welcome` |

## Account / Personal Info

**Route:** `/account`

Editable fields:
- Profile photo (via image picker — gallery or camera)
- Full Name
- Email (read-only if using OAuth)
- Phone Number (with country code)
- Date of Birth
- Gender

```dart
// account_controller.dart — pick profile photo
Future<void> pickProfilePhoto() async {
  final picker = ImagePicker();
  final image = await picker.pickImage(source: ImageSource.gallery, imageQuality: 80);
  if (image != null) {
    profileImagePath.value = image.path;
    await _profileService.updatePhoto(image.path);
  }
}
```

## Delivery Addresses

**Route:** `/delivery-address`

### Features
- List of saved addresses with full details
- Default address highlighted with a green badge
- "Set as Default" option per address
- Edit and Delete actions (swipe or long-press menu)
- "+ Add New Address" opens the Edit Address form

### Edit Address Form (`/edit-address`)

Fields powered by Google Places autocomplete:
- Address Line 1 (with autocomplete)
- Address Line 2 (optional)
- City / State / ZIP
- Country
- Label (Home / Work / Other)

```dart
// edit_address_controller.dart
void onPlaceSelected(Prediction prediction) async {
  final details = await PlacesService.getDetails(prediction.placeId!);
  streetController.text = details.formattedAddress ?? '';
  cityController.text = details.city ?? '';
  stateController.text = details.state ?? '';
  zipController.text = details.zipCode ?? '';
}
```

## Language

**Route:** `/language`

Displays all 9 supported languages as a selectable list:

| Flag | Language | Locale Code |
|------|----------|-------------|
| US | English (US) | `en_US` |
| UK | English (UK) | `en_GB` |
| DE | German | `de_DE` |
| ES | Spanish | `es_ES` |
| FR | French | `fr_FR` |
| IT | Italian | `it_IT` |
| ID | Indonesian | `id_ID` |

Tapping a language updates the app locale and saves the choice:

```dart
void selectLanguage(AppLanguage lang) {
  Get.updateLocale(lang.locale);
  GetStorage().write('locale', lang.code);
}
```

See the Localization documentation for adding new languages.

## Coupons

**Route:** `/coupons`

A wallet of available coupon cards:

```
┌─────────────────────────────────────┐
│ SAVE10                 10% OFF      │
│ Min. order: $30      Expires: Jul 1 │
│           [Copy Code]               │
└─────────────────────────────────────┘
```

Each coupon card shows: code, discount percentage, minimum order value, expiry date, and a copy-to-clipboard button.

### CouponModel

```dart
class CouponModel {
  final String code;
  final String title;
  final double discountPercent;
  final double? discountAmount;
  final double minOrderValue;
  final DateTime expiresAt;
  final bool isActive;
}
```

## Contact Us

Accessible from Settings as a bottom sheet:

- Call Support — opens phone dialer
- Email Us — opens email app
- Live Chat — placeholder for chat SDK integration

```dart
// Launching call:
launchUrl(Uri.parse('tel:+18001234567'));

// Launching email:
launchUrl(Uri.parse('mailto:support@hanago.app?subject=Support Request'));
```

:::tip Logout Flow
Logout clears all persisted data and routes back to Welcome:
```dart
void logout() {
  GetStorage().erase();
  Get.find<CartService>().clearCart();
  Get.offAllNamed(Routes.welcomeView);
}
```
:::
