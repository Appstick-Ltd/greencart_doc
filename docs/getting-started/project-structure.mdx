### What to Change

**Line 1 — App Name:**
```yaml
name: hana_go
```
Change `hana_go` to your app's name (lowercase, no spaces). This is the internal package name.

**Line 19 — Version:**
```yaml
version: 1.0.0+1
```
- `1.0.0` — the version shown to users (e.g. `1.2.0`)
- `+1` — the build number (increment this with each release, e.g. `+2`, `+3`)

**Lines 103–123 — Asset Folders:**
```yaml
flutter:
  assets:
    - assets/
    - assets/images/
    - assets/icons/
    - assets/icons/setting/
    - assets/icons/home_screen image/
    - assets/icons/navi_icon/
    - assets/icons/catagory/dairy/
    ... (more folders)
    - assets/data/
    - assets/translations/
```
When you add a new image folder, add its path here. Then run `flutter pub get`.

**Lines 151–166 — Font:**
```yaml
fonts:
  - family: Manrope
    fonts:
      - asset: assets/font/Manrope/static/Manrope-Regular.ttf
      - asset: assets/font/Manrope/static/Manrope-Bold.ttf
        weight: 700
```
The app uses the **Manrope** font. You can replace it by swapping the `.ttf` files in `assets/font/Manrope/static/` and updating this section.

**Lines 70–89 — App Icon:**
```yaml
flutter_launcher_icons:
  android: "launcher_icon"
  ios: true
  image_path: "assets/icons/logo.png"
  adaptive_icon_background: "#0D3D31"
  adaptive_icon_foreground: "assets/icons/logo.png"
```
To change the app icon, replace `assets/icons/logo.png` with your own image, then run:
```bash
dart run flutter_launcher_icons
```

This is the main working folder. Every screen, every button, every feature lives here.

### How I Built It — Layer by Layer

```
Layer 1: main.dart          →  App starts here
Layer 2: theme/             →  Colors, fonts, visual style
Layer 3: constants/         →  All design values in one place
Layer 4: models/            →  Data shapes (what a Product, User, etc. look like)
Layer 5: assets/data/       →  Product data loaded from JSON
Layer 6: data/              →  How data is loaded and stored
Layer 7: services/          →  Background workers (cart, profile, storage)
Layer 8: components/        →  Reusable UI pieces (buttons, cards, inputs)
Layer 9: pages/             →  Every screen the user sees
Layer 10: routes/           →  Maps screen names to screens
Layer 11: navigator/        →  Bottom navigation bar
```

This is the very first file Flutter runs. Here is what happens in order:

1. **Initialize storage** — loads saved settings (language, theme)
2. **Load translations** — loads all 9 language files
3. **Start the app** — opens the Splash screen

The app uses **GetX** as its state management and navigation framework. The key line:

```dart

```

This tells the app to start at the Splash screen. The Splash screen then automatically navigates to Onboarding (first run) or Home (returning users).

### How Product Data Works

The app loads products from a JSON file: `assets/data/products.json`

The loading happens in `lib/data/loaders/product_data_loader.dart`. It reads the JSON, converts each entry into a `ProductModel`, and caches everything in memory.

### Data Flow

```
assets/data/products.json
        │
        ▼
lib/data/loaders/product_data_loader.dart   ← Reads and parses JSON
        │
        ▼
lib/data/repositories/product_repository_impl.dart   ← Provides data to screens
        │
        ▼
lib/domain/repositories/product_repository.dart   ← Defines what operations exist
        │
        ▼
Screens use the data
```

### Seed Data (Default Data)

The `lib/data/seeds/` folder contains default data that ships with the app:

| File | What It Provides |
|------|-----------------|
| `default_addresses.dart` | Pre-filled delivery addresses |

| `default_orders.dart` | Sample order data |
| `default_payment_cards.dart` | Saved payment methods |

### How to Add a New Screen

**Step 1:** Create your screen in `lib/pages/my_screen/my_screen_view.dart`

**Step 2:** Add a route name in `routes/routes.dart`:
```dart
static const String myScreenView = '/my-screen';
```

**Step 3:** Connect it in `routes/pages.dart`:
```dart
_p(Routes.myScreenView, () => const MyScreenView()),
```

**Step 4:** Navigate to it from anywhere:
```dart
Get.toNamed(Routes.myScreenView);
```

## The Build Order

Here is the exact order I built this project, and the order you should follow when customizing:

```
1.  Set up Flutter environment (see Installation guide)
2.  Run the app as-is to see it work
3.  Replace logos and images (Step 3: Assets)
4.  Change colors (Step 6: Constants → ui.dart)
5.  Update app config (Step 6: Constants → app_config.dart)
6.  Edit translations (Step 3: Assets → translations/)
7.  Replace product data (Step 8: Data)
8.  Update Android/iOS settings (Step 15)
9.  Update pubspec.yaml version (Step 2)
10. Test on a real device
```

> **After each change, run `flutter run` to see the result immediately.**
