# Quick Start

Get **Hana Go** running on your device in under 5 minutes.

---

## What You Need

Before you start, make sure you have:

| Requirement | Why |
|-------------|-----|
| **Flutter SDK** installed | The app is built with Flutter |
| **Android Studio** or **VS Code** | Your code editor |
| **Android Emulator** or **Physical Device** | To run the app |

> New to Flutter? Check the [Installation Guide](./installation) for detailed setup instructions.

---

## Step 1: Extract the Downloaded Files

After purchasing from CodeCanyon, you will get a `.zip` file. Extract it to any folder on your computer.

<img src="/img/screenshots/installation/project_structure.png" alt="Extracted Folder Structure" width="600" />

After extraction, you will see:

```
hana-go-v1.0.0/
└── hana_go/          ← This is your main project folder
└── hana_go_docs/     ← Documentation site
└── README.pdf        ← Quick reference
```

**Important:** The `hana_go/` folder is what you will work with.

---

## Step 2: Open the Project in Your Editor

**Using VS Code:**
1. Open VS Code
2. Go to **File → Open Folder**
3. Select the `hana_go/` folder

**Using Android Studio:**
1. Open Android Studio
2. Click **Open**
3. Select the `hana_go/` folder

<img src="/img/screenshots/installation/vscode_open_project.png" alt="VS Code with Project Opened" width="600" />

---

## Step 3: Install Packages

Open the terminal in your editor and run:

```bash
flutter pub get
```

Wait for it to finish. You will see "Got dependencies!" when done.

<img src="/img/screenshots/installation/flutter_pub_get.png" alt="Flutter Pub Get Output" width="600" />

---

## Step 4: Run the App

### Using VS Code (Recommended)

**1. Open the Run and Debug panel:**

Click the **Run and Debug** icon in the left sidebar (or press `Ctrl+Shift+D`).

<img src="/img/screenshots/installation/vscode_run_debug.png" alt="Run and Debug Panel" width="800" />

**2. Select your device:**

From the dropdown at the top, select your emulator or connected device.

<img src="/img/screenshots/installation/vscode_select_device.png" alt="Select Device" width="800" />

**3. Click the Run button:**

Press the green **Run** button (▶) or press `F5`.

<img src="/img/screenshots/installation/vscode_click_run.png" alt="Click Run Button" width="600" />

**4. Wait for the app to build and launch:**

The first time may take 60-90 seconds. After that, it will be fast.

<img src="/img/screenshots/installation/app_running.png" alt="App Running on Device" width="350" />

### Using Terminal

```bash
# List available devices
flutter devices

# Run the app
flutter run
```

## Common Tasks After First Run

Here are the most common things you will want to change:

| What to Change | Where to Change | Guide |
|----------------|-----------------|-------|
| App name | `android/app/src/main/AndroidManifest.xml` | See below |
| App colors | `lib/constants/ui.dart` | [Colors Guide](../customization/colors-theme) |
| Logo | `assets/icons/logo.png` | [Assets Guide](../customization/assets-images) |
| Languages | `assets/translations/` | [Localization Guide](../customization/localization) |

### Change App Name (Android)

Open `android/app/src/main/AndroidManifest.xml` and find:

```xml
<application
    android:label="Your App Name"
    ...>
```

Replace `Your App Name` with your app name.

### Change App Name (iOS)

Open `ios/Runner/Info.plist` and find:

```xml
<key>CFBundleName</key>
<string>Your App Name</string>
```

Replace `Your App Name` with your app name.
