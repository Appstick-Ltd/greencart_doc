# Installation Guide

This guide walks you through everything you need to set up your development environment and run **Hana Go** on Android and iOS simulators or physical devices.

---

## Prerequisites

Before you begin, make sure you have the following installed:

| Tool | Required Version | Download |
|------|-----------------|---------|
| **Flutter SDK** | `^3.12.0` | [flutter.dev](https://docs.flutter.dev/get-started/install) |
| **Dart SDK** | Bundled with Flutter | — |
| **Android Studio** | Latest stable | [developer.android.com](https://developer.android.com/studio) |
| **Xcode** (macOS only) | 15.0+ | Mac App Store |
| **VS Code** (optional) | Latest | [code.visualstudio.com](https://code.visualstudio.com) |
| **Git** | Any recent | [git-scm.com](https://git-scm.com) |
| **Node.js** | 18+ (for docs only) | [nodejs.org](https://nodejs.org) |

## Step 2 — Install Flutter SDK

### Windows

1. Download Flutter SDK from [flutter.dev](https://docs.flutter.dev/get-started/install/windows)

![Flutter SDK Download](/img/screenshots/installation/flutter_download.png)

2. Extract the zip file to `C:\flutter`

![Extract Flutter SDK](/img/screenshots/installation/flutter_extract.png)

3. Add Flutter to your PATH environment variable:
   - Search for "Environment Variables" in Windows Search
   - Click "Edit the system environment variables"
   - Click "Environment Variables"
   - Under "System variables", select "Path" and click "Edit"
   - Click "New" and add `C:\flutter\bin`

![Add to PATH](/img/screenshots/installation/flutter_path_windows.png)

4. Open a new terminal and verify installation:

```bash
flutter --version
```

![Flutter Version Check](/img/screenshots/installation/flutter_version_check.png)

### macOS

```bash
# Using Homebrew
brew install --cask flutter

# Or manually — add to ~/.zshrc or ~/.bash_profile
export PATH="$HOME/flutter/bin:$PATH"

# Verify
flutter --version
```

### Linux

```bash
# Download the .tar.xz from flutter.dev and extract
export PATH="$PATH:`pwd`/flutter/bin"

# Verify
flutter --version
```

## Step 4 — Run Flutter Doctor

`flutter doctor` checks your environment for missing dependencies:

```bash
flutter doctor
```

![Flutter Doctor Command](/img/screenshots/installation/flutter_doctor_command.png)

Resolve any issues it reports. A healthy output looks like:

![Flutter Doctor Output](/img/screenshots/installation/flutter_doctor_output.png)

```
Flutter (Channel stable, 3.22.x)
Android toolchain - develop for Android devices
Xcode - develop for iOS and macOS (Xcode 15.x)
Android Studio (version 2024.x)
VS Code (version 1.9x.x)
Connected device (2 available)
Network resources
```

:::warning Common Issues
- **Android licenses not accepted**: Run `flutter doctor --android-licenses` and accept all.
- **Xcode not found**: Install Xcode from the Mac App Store and run `sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer`.
- **CocoaPods missing**: Run `sudo gem install cocoapods`.
:::

## Step 5 — Set Up an Emulator or Device

### Android Emulator

1. Open **Android Studio** → **Device Manager**

![Open Device Manager](/img/screenshots/installation/android_studio_device_manager.png)

2. Click **Create Device**

![Create Device Button](/img/screenshots/installation/create_device_button.png)

3. Choose a device (e.g., Pixel 8) and select a system image (API 34+)

![Select Device](/img/screenshots/installation/select_device.png)

4. Click **Finish** to complete setup, then click the play button to launch the emulator

![Emulator Running](/img/screenshots/installation/emulator_running.png)

### iOS Simulator (macOS only)
```bash
# List available simulators
xcrun simctl list devices

# Open a simulator
open -a Simulator
```

### Physical Device
- **Android**: Enable Developer Options, USB Debugging, then connect via USB
- **iOS**: Trust the computer when prompted, or use wireless development in Xcode 14+

## Step 6 — Install Dependencies

After cloning the project (see [Quick Start](./quick-start)), install all Flutter packages:

```bash
flutter pub get
```

![Flutter Pub Get](/img/screenshots/installation/flutter_pub_get.png)


## Step 7 — Install VS Code

1. Download VS Code from [code.visualstudio.com](https://code.visualstudio.com/)

![VS Code Download](/img/screenshots/installation/vscode_download.png)

2. Run the installer and complete the installation

3. Launch VS Code

![VS Code Launch](/img/screenshots/installation/vscode_launch.png)

### Install Extensions

1. Press `Ctrl+Shift+X` to open Extensions

![VS Code Extensions](/img/screenshots/installation/vscode_extensions.png)

2. Search for **Flutter** and click Install

![Flutter Extension](/img/screenshots/installation/flutter_extension.png)

3. Search for **Dart** and click Install

![Dart Extension](/img/screenshots/installation/dart_extension.png)

4. Install these additional extensions:
   - **Pubspec Assist** — for managing pub dependencies
   - **Flutter Widget Snippets** — code snippets
   - **Error Lens** — inline error highlighting

![Additional Extensions](/img/screenshots/installation/additional_extensions.png)

## Step 8 — Run the App

### Using VS Code (Recommended)

1. Open the project folder in VS Code

![Open Project](/img/screenshots/installation/vscode_open_project.png)

2. Click **Run and Debug** in the sidebar (or press `Ctrl+Shift+D`)

![Run and Debug](/img/screenshots/installation/vscode_run_debug.png)

3. Select your device from the dropdown

![Select Device](/img/screenshots/installation/vscode_select_device.png)

4. Click **Run** or press `F5`

![Click Run](/img/screenshots/installation/vscode_click_run.png)

5. Wait for the app to build and launch

![App Running](/img/screenshots/installation/app_running.png)

### Using Terminal

```bash
# List available devices
flutter devices

# Run on connected device/emulator
flutter run

# Run on a specific device
flutter run -d <device-id>
```

![Flutter Run Terminal](/img/screenshots/installation/flutter_run_terminal.png)

## Build for Production

### Android APK
```bash
flutter build apk --release
# Output: build/app/outputs/flutter-apk/app-release.apk
```

### Android App Bundle (for Play Store)
```bash
flutter build appbundle --release
# Output: build/app/outputs/bundle/release/app-release.aab
```

---

:::tip Hot Reload and Hot Restart
- **Hot Reload** (`r` in terminal or `Ctrl+R`): Updates UI instantly without losing state — great for UI tweaks.
- **Hot Restart** (`R` in terminal or `Ctrl+Shift+R`): Full restart, resets state — use when changing controllers or bindings.
:::
