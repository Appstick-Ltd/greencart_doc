## 📦 Full Dependencies Reference

### State Management & Navigation

| Package | Version | Purpose |
|---------|---------|---------|
| `get` | `^4.6.6` | GetX — state management, routing, dependency injection, translations |

GetX is the backbone of Hana Go. It handles:
- **Reactive state** with `.obs` and `Obx()`
- **Named routing** with page bindings
- **Dependency injection** with `Get.put()` / `Get.find()`
- **Translations** with `.tr` extension

### Storage & Persistence

| Package | Version | Purpose |
|---------|---------|---------|
| `get_storage` | `^2.1.1` | Fast key-value storage for app state, cart, preferences |
| `flutter_secure_storage` | `^9.0.0` | Encrypted storage for auth tokens (uses Keychain / Keystore) |
| `hive_flutter` | `^1.1.0` | Lightweight NoSQL database for structured offline data |

**When to use which:**
- `get_storage` → Cart items, language preference, onboarding flag, theme
- `flutter_secure_storage` → Auth tokens, user ID, sensitive session data
- `hive_flutter` → Larger structured data sets like notification history

## 🔍 Package Decision Rationale

| Decision | Reason |
|----------|--------|
| **GetX over Bloc/Riverpod** | Less boilerplate for a UI template; integrated routing and DI reduce file count significantly |
| **dio over http** | Interceptors for auth token injection; better error handling and multipart support |
| **get_storage over SharedPreferences** | GetX-native, no async init required, reactive reads |
| **flutter_secure_storage** | Platform Keychain/Keystore for token security — required for production |
| **Manrope font** | Excellent readability at small sizes, wide weight range, Google Fonts license |
